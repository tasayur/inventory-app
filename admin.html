⚙️ 管理者設定

‹ メインアプリへ戻る

① Supabase設定（データベース）

1
supabase.com でアカウント作成（無料・クレカ不要）
2
「New Project」でプロジェクト作成
3
Project Settings → API → Project URLとanon keyをコピーして下に貼り付け

📱 iPhoneでこのQRコードを読み取ると、設定が自動で引き継がれます：

スキャン後、メインアプリが開きます

② EmailJS設定（メール通知）

1
emailjs.com でアカウント作成（無料・200通/月）
2
Email Services → Gmail や Outlook を連携
3
Email Templates → 新規作成。件名: {{subject}}、本文: {{operation}}：{{item_name}}\n{{qty_info}}\n担当：{{operator}}\n日時：{{datetime}}\n備考：{{notes}}
4
Account → Public Key をコピー
